Culinary Creations

📌 Project Overview

Culinary Creations is a modern and responsive restaurant landing page developed using HTML5 and CSS3. It includes an attractive hero section with a background overlay, smooth food image rotation effects, stylish call-to-action buttons, and user-friendly navigation.

• Frontend Technologies: HTML5, CSS3
• Key Elements: Font Awesome Icons, CSS Keyframe Animations

The website offers a visually appealing interface to showcase restaurant services, highlight food items, encourage table reservations, and explore the menu.

📌 Features

• Responsive hero section featuring an attractive background image with an overlay effect.
• Smooth CSS rotation animation for the main food images.
• Stylish navigation bar with interactive buttons.
• Font Awesome icons for enhanced visual presentation.
• Modern typography with attractive call-to-action buttons.
• Clean and user-friendly layout for a better browsing experience.
